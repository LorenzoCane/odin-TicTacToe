# Tic Tac Toe

Odin Project Assignment: [Tic Tac Toe](https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe)

Project of the JavaScript Course

Goal: Use factory functions and module pattern to build a working Tic Tac Toe game. Try to use as less global code as possible

N.B: I only complete a first draft where I implement a full PvsP game. there is no possibility to play against a computer


## Try it

You can try the game at [Tic Tac Toe](https://lorenzocane.github.io/odin-TicTacToe/)
